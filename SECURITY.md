# Security policy

fieldsim is a **test tool**. Its simulated devices accept anonymous, unencrypted
connections (OPC UA security mode None, plain Modbus and S7) and make no attempt
to resist hostile clients. Do not expose them to untrusted networks.

## Supported versions

Security fixes are made for the latest minor release.

## Reporting a vulnerability

Please do not open a public issue. Use
[GitHub's private vulnerability reporting](https://github.com/enesuslu15/fieldsim/security/advisories/new)
instead. You will get an answer within a week.
